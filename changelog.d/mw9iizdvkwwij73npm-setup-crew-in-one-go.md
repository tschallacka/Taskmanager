- **Set up a crew in one go: `crew setup`.** One kit command makes the crew for a board: it creates the crew bound to the board, fetches its keys once into the crew home's `creds.json` (mode 600, nothing printed), writes `crew.json` with the crew's shadow board as the work board (by id and url) and the real board as read-only context, and runs `init` so the agent types exist. The management token comes from `TASKMANAGER_MANAGEMENT_TOKEN` or stdin, never from the command line. A taken slug stops with a 409 and nothing is rotated. The files written in the crew home (`creds.json`, `crew.json`) are created at mode 600. `crew/setup.mjs`, `crew/setup.test.mjs`, `crew/crew.mjs`, `crew/README.md`, `app/utils/managementPrompt.ts`, `tests/management-prompt.test.ts`.
