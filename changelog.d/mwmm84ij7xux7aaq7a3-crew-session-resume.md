- **Crew session resume: the full session id is kept, and a refused resume is said, not hidden.** `claude agents --json` gives a background session a short `id` and the full `sessionId`; the record kept the short one, so `crew session start` could not resume a stopped session and started a fresh one with a new id. The record now holds the full id, a record that still holds the short id is resolved through what agents lists, and a refused resume prints `resume refused: <reason>, started fresh`. Files: `crew/session.mjs`, `crew/session.test.mjs`.
- **A stopped session resumes with its own id.** A resume is now the bare `claude --bg --resume <id>`: any other flag makes claude start a copy under a new id. `crew session stop` sends `claude stop` the short id that agents shows, since the full id gets "No session matching". Files: `crew/session.mjs`, `crew/session.test.mjs`.
