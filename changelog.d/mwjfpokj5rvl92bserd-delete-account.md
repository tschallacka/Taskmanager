- **Delete my account: the rules for every column that holds a person's user id.** Each such column is decided in one rule table (delete, keep as "Deleted user", or clear), and a test fails when a new user column has no rule. The deletion itself removes a personal board with no other member, with its tasks and attachment files, keeps a team's work under "Deleted user", and clears the columns the person filled in. Files: `server/utils/accountRules.ts`, `server/utils/accountDeletion.ts`, `tests/account-deletion-coverage.test.ts`, `tests/account-deletion.test.ts`.
