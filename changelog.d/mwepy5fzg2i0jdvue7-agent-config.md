- **Connect a folder or an agent with its own MCP setup, not a shared variable.** The key panel offers two copies. **Copy agent config file** writes a per-agent file, started with `claude --mcp-config <file> --strict-mcp-config`, with a server name unique per instance, board and key. **Copy folder setup** writes only `.mcp.json` and `.claude/settings.local.json` in one folder: the header reads a variable named for the key, and nothing goes to user settings or a shell profile. Both files are excluded from git. The check is `/mcp` inside a session, and a reconnect is a new session (`claude --continue`). A key's name suffix (`-2`, `-3`) is stored on its row in a new nullable column `api_keys.name_suffix`, added with `db:push` (the repo keeps no migration SQL). Check it on live after deploy: the column exists and the key list returns `nameSuffix`.
