- **Pasting an image into a task description shows its progress.** A pasted image shows an "Uploading image…" placeholder with a bar that fills as the upload goes, then the image. A failed upload leaves a visible line with the reason, which stays until you delete it. Several pasted images each get their own placeholder. Files: `app/utils/editor/`, `app/components/RichEditor.vue`, `app/components/kanban/TaskDrawer.vue`.
- **Pasted images are not dropped when you type at a pending placeholder.** A late answer to an earlier save no longer puts back the text from before the typing and takes the placeholders out, so the upload lands (or shows its error line). Files: `app/utils/editor/imagePlaceholders.ts`, `app/components/kanban/TaskDrawer.vue`.
