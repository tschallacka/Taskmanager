- **Pia's terminal is a tmux session; `crew up`, `crew stop` and `crew restart` run her start, stop and restart.** Pia's Claude Code session runs in the tmux session `pia` on the crew's socket. `crew/pia-tmux.mjs` (new) resumes her recorded session id (a fresh start only when no id is recorded), checks her screen for a dialog, pastes a test mail and checks it shows, then starts her board listener with the command her hook runs and reports its pid; a listener that does not come up is a FAIL line. Stop sends `/exit`, answers the background-shell exit confirm once, and kills the session after the grace time. A start in a home with no `crew.json` is refused before anything runs. `crew/pia-term.sh` (new) is the adapter the mailbox daemon types into, now on tmux. `crew/people-control.mjs` routes `up`, `restart` and `stop` for Pia through it, and `crew/session.mjs` notes that `claude stop` is verified. Files: `crew/pia-tmux.mjs`, `crew/pia-term.sh`, `crew/people-control.mjs`, `crew/session.mjs`, `crew/PROMPTS.md.tmpl`, `crew/kit-files.txt`, with the tests in `crew/pia-tmux.test.mjs`, `crew/pia-term.test.mjs` and `crew/people-control.test.mjs`.
