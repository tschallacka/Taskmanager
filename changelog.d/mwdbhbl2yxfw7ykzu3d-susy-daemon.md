- **Susy can run as a daemon with no model in the loop (dry-run only).** `crew susy-daemon once` runs one tick: it reads the board with Susy's own key, runs the same round as `crew susy check`, and logs what it would post, one line per new action, to `.listen/susy-daemon-dryrun.log`. Each tick writes `.listen/susy-daemon.json`, the heartbeat. `crew susy-daemon loop` ticks every 60 seconds and `status` shows the heartbeat. It posts nothing and sends no mail in this build, and `--live` is refused. Creds trouble logs one line and one would-mail-Boss line per streak. The board read in `crew/susy.mjs` is now shared with the daemon (`makeCall`, `readBoardCards`). Files: `crew/susy-daemon.mjs`, `crew/susy-daemon.test.mjs`, `crew/susy.mjs`, `crew/crew.mjs`, `crew/kit-files.txt`.
