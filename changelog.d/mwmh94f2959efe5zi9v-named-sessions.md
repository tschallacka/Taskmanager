- **Named sessions; `crew up` resumes; remote control off for Pia.** Every person's background session is named `<crew slug>-<key>` (for example `taskmanager-maintenance-wren`), so `claude --resume <name>` finds it. A start with a recorded session id that is not live resumes that session (`claude --bg --resume <id>`): the same id and transcript come back. A resume that claude refuses falls back to a fresh start and records the new id. Pia's session file (`pia-session.settings.json`) turns `remoteControlAtStartup` off, and her start line names her session `<crew slug>-pia`. Tests in `crew/session.test.mjs` and `crew/claude.test.mjs`.
